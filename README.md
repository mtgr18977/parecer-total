# Street Fighter 6 Hub

Seu centro completo de recursos para dominar Street Fighter 6.

## Funcionalidades

- **Calculadora de Frames:** Calcule vantagens, verifique se golpes são puníveis e analise gaps em blockstrings.
- **Combos por Personagem:** Biblioteca completa de combos organizados por dificuldade.
- **Frame Data Completo:** Consulte frame data detalhado de todos os personagens com explicações interativas.
- **Matchup Helper:** Compare matchups entre personagens, veja vantagens e desvantagens estratégicas.
- **Glossário de Termos:** Aprenda terminologias essenciais.

## Como usar localmente

1. **Clone ou copie este projeto para sua máquina.**

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor local:**
   ```bash
   npm start
   ```
   O sistema estará disponível em [http://localhost:3000](http://localhost:3000).

## Tradução

O aplicativo suporta Português (pt-BR) e Inglês (en). Você pode trocar o idioma através do seletor na barra de navegação.
